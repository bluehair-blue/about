# 한파란 포트폴리오

서브컬쳐 AI 챗봇 기획자 한파란의 포트폴리오 레퍼런스 사이트입니다.

- `#work`: 작품 목록
- `#support`: 후원 안내
- `#now`: 제작 근황

콘텐츠는 `app/page.tsx`, 색상과 레이아웃은 `app/globals.css`에서 수정합니다. 모든 작성 색상은 OKLCH를 사용합니다.

```bash
npm run dev
npm run build
npm test
npm run deploy
```

배포 주소는 `https://about.bluehair.blue`이며, Worker 미리보기는 `https://about.odeye3217.workers.dev`에서 확인할 수 있습니다.
